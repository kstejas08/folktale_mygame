Geo_Guesser!

->Geo_Guesser is a fun, interactive python text adventure game where you solve clues to guess the country! start by guessing the planet, then the continent, then answer two clue questions before making your final country guess.
->The game includes funny responses, unlimited retries, a guess counter and an option to play again.
->Built using beginner python functions: print(),input(),variables,if/elif/else and while loops.

HOW TO PLAY?
->Run the game with python
->Type your answers in the terminal and press Enter. Answers will ignore capitals and extra spaces.
